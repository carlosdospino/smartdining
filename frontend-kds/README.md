# 🍳 Frontend KDS (Kitchen Display System)

**Responsable:** Carlos Ospino (Integrante 3)

## Descripción
Pantalla de visualización para la cocina (KDS - Kitchen Display System). Diseñada para operar en pantallas táctiles o monitores en el área de cocina/preparación.

## Características Clave
- Clasificación de comandas por tiempo de llegada y orden de prioridad.
- Detalle de ítems con notas especiales de preparación (sin cebolla, término medio, etc.).
- Cambio rápido de estados: "En preparación" ➔ "Listo para entrega".
- Alertas visuales y sonoras ante nuevos pedidos en tiempo real.
